EASM 데모 개인정보처리방침

이 안내는 제한된 합성 데이터 테스트용 EASM 선언형 에이전트와 이 안내 페이지에 적용됩니다.

입력과 서비스 처리

합성 데이터만 입력하세요. 실제 개인 정보, 자격 증명, 고객 정보 및 업무 데이터는 입력하지 마세요. 입력 내용과 응답, 계정 정보 및 서비스 진단 정보는 Microsoft 365와 테스트 테넌트의 설정 및 정책에 따라 처리될 수 있습니다.

데모의 선언형 에이전트에는 외부 지식이나 API 작업을 구성하지 않습니다. 이 설정이 Microsoft 365 서비스의 처리 또는 로그가 없다는 뜻은 아닙니다.

페이지 접속

이 페이지는 GitHub Pages에서 호스팅합니다. GitHub가 페이지 제공과 보안을 위해 접속 관련 정보를 처리할 수 있습니다.

문의와 관련 정책

테스트 테넌트에서의 데이터 처리, 보존, 삭제 요청은 해당 테넌트 관리자에게 문의하세요. 서비스별 처리에 관한 자세한 내용은 다음 정책을 확인하세요.

  • Microsoft 개인정보처리방침
  • GitHub 개인정보처리방침

이 안내는 데모용이며 운영 또는 일반 공개 서비스에 필요한 조직별 개인정보처리방침을 대체하지 않습니다.
